# Verdant Reach · first-person prototype

Standalone 3D exploration experiment for **The Hollow Roots**. It has its own package, build, save key, and deployment. The 2D game is untouched.

## Play

```sh
npm install
npm run dev
```

Click **Enter the Forest** to capture the mouse. Move with WASD, look with the mouse, run with Shift, strike with left click, interact with E, open the journal with J, and pause with Escape. Find three memories along branching trails and return to the Canopy Gate. Exploration progress saves in the browser.

This is a prototype biome, not an open-world production release. The shellbacks and thornlings are 3D animated creatures; defeating them does not award XP. Future integration with the main game's real-world stats is deliberately separate from this experiment.
